An entry for the [make.fun](https://make.fun) competition **The Funniest Honest Appliance Error** (slug `u-xvader-the-funniest-honest-appliance-error-adec4450`).

## The entry

`main.py` writes one line of at most 200 characters to `/output/entry.txt`: the funniest honest error message an appliance could show.

> ERROR: Temperature sensor drifting. I said 200 degrees. I meant 140. I have been lying for months.

The line was chosen from 36 candidates by pairwise judging against the judge's brief: an honest fault (oven temperature sensor drift), a real twist (the oven calmly confessing months of false readings), the machine's own flat, put-upon voice, and economy — every word earns its place.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
